一棵决策树：从表格到分裂规则

这棵示例树使用贪心算法：每一步都寻找当前节点中让不纯度下降最大的分裂。 为了和课程公式对应，下面先用“胸痛类型是否为无症状型”做根节点分裂， 再在右侧节点用“胆固醇是否大于等于 245”继续分裂。

根节点的不纯度

分类错误率： Classification Error(R) = 1 - max(p_yes, p_no) = 1 - max(6/12, 6/12) = 1 - 0.5 = 0.5 基尼指数： Gini(R) = 1 - (6/12)^2 - (6/12)^2 = 1 - 0.25 - 0.25 = 0.5 熵： Entropy(R) = - (6/12)log2(6/12) - (6/12)log2(6/12) = - 0.5log2(0.5) - 0.5log2(0.5) = 1.000

第一次分裂：胸痛类型是否为无症状型

左子节点 A 有 5 人，全部有病；右子节点 B 有 7 人，其中 1 人有病、6 人无病。

左节点 A： Gini(A) = 1 - (5/5)^2 - (0/5)^2 = 0 Error(A) = 1 - max(5/5, 0/5) = 0 Entropy(A) = 0 右节点 B： Gini(B) = 1 - (1/7)^2 - (6/7)^2 = 1 - 1/49 - 36/49 = 12/49 = 0.2449 Error(B) = 1 - max(1/7, 6/7) = 1 - 6/7 = 1/7 = 0.1429 Entropy(B) = - (1/7)log2(1/7) - (6/7)log2(6/7) = 0.5917
加权平均不纯度： Weighted Gini = (5/12)Gini(A) + (7/12)Gini(B) = (5/12)(0) + (7/12)(12/49) = 1/7 = 0.1429 Weighted Error = (5/12)(0) + (7/12)(1/7) = 1/12 = 0.0833 Weighted Entropy = (5/12)(0) + (7/12)(0.5917) = 0.3451 不纯度下降： Delta Gini = Gini(R) - Weighted Gini = 0.5000 - 0.1429 = 0.3571 Delta Entropy = 1.0000 - 0.3451 = 0.6549

第二次分裂：在节点 B 中看胆固醇是否大于等于 245

节点 B 的 7 人中，只有 ID 8 的胆固醇为 248 且有病；其余 6 人胆固醇低于 245 且无病。 因此这一步把节点 B 分成两个纯叶节点。

节点 B 分裂前： Gini(B) = 12/49 = 0.2449 胆固醇 >= 245：1人，有病1 / 无病0 Gini(B1) = 0 胆固醇 < 245：6人，有病0 / 无病6 Gini(B2) = 0 Weighted Gini after split = (1/7)(0) + (6/7)(0) = 0 节点 B 内部的不纯度下降： Delta Gini_B = 0.2449 - 0 = 0.2449 按整棵树样本比例加权后的贡献： (7/12) * 0.2449 = 0.1429

随机森林：三棵树投票

随机森林保留自助采样和投票聚合，同时在每个节点只考虑一小部分随机特征。 本表共有 p = 9 个特征，分类任务的经验起点是：

m_try ≈ sqrt(p) = sqrt(9) = 3

所以每个分裂节点只随机抽取约 3 个候选特征，再从这 3 个特征中找最佳分裂。

袋装分类多数投票

y_hat = mode{y_hat_1, y_hat_2, ..., y_hat_B} 本例 B = 3： Tree 1 = 有病 Tree 2 = 有病 Tree 3 = 有病 y_hat = mode{有病, 有病, 有病} = 有病

随机森林类别概率估计

P_hat(Y = 有病 | x) = (1/B) * sum_{b=1}^B P_hat_b(Y = 有病 | x) = (0.80 + 0.75 + 0.67) / 3 = 2.22 / 3 = 0.74 解释：这不是严格校准后的医学概率，而是随机森林模型给出的类别概率估计。

评估公式与完整算式

准确率与 F1

假设随机森林在 12 条样本上得到如下混淆矩阵： TP=5，TN=5，FP=1，FN=1。

Accuracy = (TP + TN) / (TP + TN + FP + FN) = (5 + 5) / (5 + 5 + 1 + 1) = 10 / 12 = 0.8333 Precision = TP / (TP + FP) = 5 / (5 + 1) = 5/6 = 0.8333 Recall = TP / (TP + FN) = 5 / (5 + 1) = 5/6 = 0.8333 F1 = 2 * Precision * Recall / (Precision + Recall) = 2 * 0.8333 * 0.8333 / (0.8333 + 0.8333) = 0.8333

袋外预测与袋外误差

OOB 只用“训练时没见过该样本”的树做预测，避免把同一个样本既用于训练又用于评估。

对第 i 个样本： y_hat_i^OOB = mode{y_hat_b(x_i) : 样本 i 不在第 b 棵树的自助训练集中} 示例 4 个 OOB 点： ID 1：真实=否，OOB预测={否, 否} → y_hat^OOB=否，误差=0 ID 2：真实=是，OOB预测={是, 是} → y_hat^OOB=是，误差=0 ID 8：真实=是，OOB预测={否, 是, 是} → y_hat^OOB=是，误差=0 ID 9：真实=是，OOB预测={否, 否} → y_hat^OOB=否，误差=1 OOB Error = (0 + 0 + 0 + 1) / 4 = 0.25

MDI：平均不纯度下降

MDI 的核心是：某个特征在树里带来的基尼下降越大、覆盖样本越多， 它对模型越重要。下面先算第一棵树，再做森林平均。

单节点贡献公式： MDI(t) = (N_t / N) * [G(t) - (N_L/N_t)G(t_L) - (N_R/N_t)G(t_R)] Tree 1 根节点使用“胸痛类型”： N = 12, N_t = 12, G(t)=0.5000 分裂后加权 Gini = 0.1429 MDI_root = (12/12) * (0.5000 - 0.1429) = 0.3571 Tree 1 第二节点使用“胆固醇”： N = 12, N_t = 7, G(t)=12/49=0.2449 分裂后加权 Gini = 0 MDI_chol = (7/12) * (0.2449 - 0) = 0.1429 Tree 1 未归一化贡献总和： 0.3571 + 0.1429 = 0.5000 Tree 1 归一化重要性： FI_胸痛,T1 = 0.3571 / 0.5000 = 0.7142 FI_胆固醇,T1 = 0.1429 / 0.5000 = 0.2858
森林平均公式： FI_j^forest = (1/B) * sum_{b=1}^B FI_{j,T_b}^norm 假设三棵树的归一化贡献如下： Tree 1：胸痛 0.7142，胆固醇 0.2858 Tree 2：最大心率 0.4400，ST压低 0.3600，运动心绞痛 0.2000 Tree 3：年龄 0.3200，运动心绞痛 0.2800，胸痛 0.2000，胆固醇 0.1000，最大心率 0.1000 胸痛重要性 = (0.7142 + 0 + 0.2000) / 3 = 0.3047 最大心率重要性 = (0 + 0.4400 + 0.1000) / 3 = 0.1800 运动心绞痛重要性 = (0 + 0.2000 + 0.2800) / 3 = 0.1600 胆固醇重要性 = (0.2858 + 0 + 0.1000) / 3 = 0.1286 ST压低重要性 = (0 + 0.3600 + 0) / 3 = 0.1200 年龄重要性 = (0 + 0 + 0.3200) / 3 = 0.1067

置换重要性

置换重要性固定训练好的模型，只打乱验证集或 OOB 数据中的某一列， 观察模型表现下降多少。

PI_j = S - (1/K) * sum_{k=1}^K S_{j,k}^perm 假设原始准确率： S = 10/12 = 0.8333 打乱“胸痛类型”3次后的准确率： 7/12, 8/12, 7/12 平均 = (7/12 + 8/12 + 7/12) / 3 = 22/36 = 0.6111 PI_胸痛 = 0.8333 - 0.6111 = 0.2222 打乱“最大心率”3次后的准确率： 8/12, 9/12, 8/12 平均 = 25/36 = 0.6944 PI_最大心率 = 0.8333 - 0.6944 = 0.1389

补充：复杂度控制与剪枝

单棵树越深，通常偏差更低但方差更高，所以可能过拟合。 除了最大深度、最小叶节点样本数、最大叶节点数等停止条件，也可以先让树长出来，再剪枝。

代价复杂度剪枝： C_alpha(T) = Err(T) + alpha * |T| 假设完整树 T： Err(T) = 0, |T| = 3, alpha = 0.25 C_alpha(T) = 0 + 0.25 * 3 = 0.75 假设剪枝树 T'： Err(T') = 2/12 = 0.1667, |T'| = 2 C_alpha(T') = 0.1667 + 0.25 * 2 = 0.6667 因为 0.6667 < 0.75，在 alpha=0.25 时，剪枝树 T' 更划算。
剪枝选择比率： g(T, T') = [Err(T') - Err(T)] / [|T| - |T'|] = (0.1667 - 0) / (3 - 2) = 0.1667 解释：每减少 1 个叶节点，需要付出 0.1667 的训练误差增加。 比率越小，说明这次剪枝越划算。

把所有知识点串起来

决策树 用不纯度指标选择局部最优分裂；本例中“胸痛类型”和“胆固醇”把 12 个样本分到纯叶节点。
袋装法 对每棵树做自助采样，再用多数投票聚合分类结果，用来降低单棵深树的方差。
随机森林 在袋装法基础上加入特征随机性：每个节点只看 m_try 个候选特征，从而降低树相关性。
变量重要性 MDI 看训练时的不纯度下降，置换重要性看打乱特征后模型表现下降多少。
