## 分类准确率

| 代码行 | 作用 |
|---|---|
| `from sklearn.metrics import accuracy_score` | 导入分类准确率函数。 |
| `single_acc = accuracy_score(y_test, prediction)` | 比较真实标签和单棵树预测，计算准确率。 |
| `bagging_accuracy = accuracy_score(y_test, y_pred)` | 计算 Bagging 集成预测的准确率。 |
| `np.mean(y_pred == y_test)` | 通过布尔比较的平均值手算准确率。 |
| `print(f'Single tree Accuracy is {single_acc * 100}%')` | 将 0 到 1 的准确率转换为百分比输出。 |

相关概念：[[模型准确率 (Model Accuracy)]]、[[分类任务 (Classification Task)]]。

## 回归均方误差

| 代码行 | 作用 |
|---|---|
| `from sklearn.metrics import mean_squared_error` | 导入均方误差函数。 |
| `mse_single = mean_squared_error(y_test, y_pred1)` | 计算单个基回归树的测试 MSE。 |
| `mse_bagging = mean_squared_error(y_test, y_pred)` | 计算 Bagging 平均预测的测试 MSE。 |
| `round(mse_bagging, 2)` | 将显示结果四舍五入到两位小数。 |

相关概念：[[均方误差 (Mean Squared Error)]]、[[回归任务 (Regression Task)]]。

## F1 与 ROC AUC

| 代码行 | 作用 |
|---|---|
| `from sklearn.metrics import f1_score, roc_auc_score` | 导入不平衡分类常用的 F1 和 ROC AUC 指标。 |
| `f_score = f1_score(np.ravel(y_val), predictions)` | 计算二分类正类的 F1 分数。 |
| `y_proba = model.predict_proba(X_test)[:, 1]` | 提取正类预测概率，作为 ROC AUC 的连续评分。 |
| `auc = roc_auc_score(y_test, y_proba)` | 用真实标签和正类评分计算 ROC 曲线下面积。 |

测试题 `exe44` 直接把硬类别 `predictions` 传给 `roc_auc_score()`；这能得到数值，但实际模型比较更推荐使用正类概率或 `decision_function()` 分数。

## 决策树特征重要性

```python
feature_importance = pd.Series(                         # 将 NumPy 重要性数组包装成带特征名的 Series
    dt3.feature_importances_,                           # 读取训练后决策树的特征重要性
    index=pred_cols,                                    # 用特征列名作为索引
    name='importance',                                  # 为结果 Series 命名
).sort_values(ascending=False)                          # 按重要性从高到低排序
```

| 代码行 | 作用 |
|---|---|
| `dt3.feature_importances_` | 读取树模型基于不纯度下降计算的特征重要性数组。 |
| `feature_importance.sort_values()` | 按从低到高排序，便于绘制水平条形图。 |
| `feature_importance.sort_values().plot(kind='barh', color='steelblue')` | 绘制特征重要性水平条形图。 |

相关概念：[[变量重要性 (Variable Importance)]]、[[平均不纯度下降 (Mean Decrease in Impurity)]]。

## Permutation Importance

```python
tree_result = permutation_importance(                            # 计算单棵决策树的置换重要性
    tree, X, y, random_state=random_state                        # 传入已拟合模型、评估数据并固定置换
)                                                               # 返回各特征多轮置换后的分数下降
forest_result = permutation_importance(                          # 计算随机森林的置换重要性
    forest, X, y, random_state=random_state                      # 使用同一数据和随机状态便于比较
)                                                               # 返回 Bunch 结果对象
```

| 属性 | 作用 |
|---|---|
| `result.importances` | 形状为 `(n_features, n_repeats)` 的每轮分数下降。 |
| `result.importances_mean` | 每个特征跨重复置换的平均重要性。 |
| `result.importances_std` | 每个特征重要性的标准差。 |

与树的 `feature_importances_`（MDI）不同，Permutation Importance 会打乱某一特征并观察模型分数下降，因此可用于任意已拟合估计器；评估集和 `scoring` 的选择会直接影响结果。
