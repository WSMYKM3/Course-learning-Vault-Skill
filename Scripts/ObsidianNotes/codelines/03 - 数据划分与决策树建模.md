# 数据划分与决策树建模

返回索引：[[00 - Codelines 索引]]

本页函数逐参数说明：[[10 - scikit-learn 函数参数详解]]、[[11 - Matplotlib 函数参数详解]]。

## 划分训练集和测试集

| 代码行 | 作用 |
|---|---|
| `from sklearn.model_selection import train_test_split` | 导入随机训练测试集划分函数。 |
| `X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=44)` | 将 20% 数据作为测试集，并固定随机划分结果。 |
| `x_train, x_test, y_train, y_test = train_test_split(x, y, train_size=0.8, random_state=102)` | 将 80% 数据作为训练集；效果等价于 `test_size=0.2`。 |

`random_state` 用于复现实验划分。相关概念：[[训练数据 (Training Data)]]、测试数据。

## 创建分类树

| 代码行 | 作用 |
|---|---|
| `from sklearn.tree import DecisionTreeClassifier` | 导入决策树分类器。 |
| `clf = DecisionTreeClassifier(max_depth=3, random_state=44)` | 创建最大深度为 3、结果可复现的分类树。 |
| `dtree = DecisionTreeClassifier(criterion='gini', max_depth=3)` | 明确使用 Gini 不纯度作为切分标准。 |
| `dt1 = DecisionTreeClassifier(max_depth=2, random_state=0)` | 创建浅树，通常偏差较高、方差较低。 |
| `dt2 = DecisionTreeClassifier(max_depth=10, random_state=0)` | 创建更深的树，用于比较复杂度与泛化表现。 |
| `dt3 = DecisionTreeClassifier(max_depth=15, random_state=0)` | 创建高复杂度树，用于观察过拟合和特征重要性。 |

相关概念：[[决策树 (Decision Tree)]]、[[最大深度 (Maximum Depth)]]、[[基尼指数 (Gini Index)]]、[[过拟合 (Overfitting)]]。

## 训练模型

| 代码行 | 作用 |
|---|---|
| `clf.fit(X_train, y_train)` | 用训练特征和训练标签拟合分类树。 |
| `dtree.fit(elect_train[['minority']], y_train)` | 只使用一个特征训练分类树。 |
| `sklearn_tree.fit(X, y)` | 使用全部给定数据拟合教学示例树。 |

## 预测和模型内置评分

| 代码行 | 作用 |
|---|---|
| `prediction = clf.predict(X_test)` | 为测试样本输出预测类别。 |
| `dt1_train_acc = dt1.score(X_train, y_train)` | 计算分类树在训练集上的平均准确率。 |
| `dt1_test_acc = dt1.score(X_test, y_test)` | 计算分类树在测试集上的平均准确率。 |

## 绘制树结构

| 代码行 | 作用 |
|---|---|
| `from sklearn import tree` | 导入 scikit-learn 的树工具模块。 |
| `plt.figure(figsize=(30, 20))` | 创建足够大的画布以容纳树结构。 |
| `tree.plot_tree(dtree, filled=True)` | 绘制树，并按节点类别或输出值填充颜色。 |
| `tree.plot_tree(sklearn_tree, fontsize=6)` | 以较小字号绘制较复杂的树。 |

## 一个最小的分类树流程

```python
X_train, X_test, y_train, y_test = train_test_split(         # 同时划分特征和标签
    X, y, test_size=0.2, random_state=44                     # 保留 20% 测试数据并固定随机状态
)                                                               # 结束 train_test_split 调用
clf = DecisionTreeClassifier(max_depth=3, random_state=44)   # 创建受深度限制的分类树
clf.fit(X_train, y_train)                                    # 从训练集学习分割规则
y_pred = clf.predict(X_test)                                 # 预测测试样本类别
test_accuracy = clf.score(X_test, y_test)                    # 直接计算测试准确率
```
