## 检查类别比例

```python
count0, count1 = df['Outcome'].value_counts()                    # 读取两个类别各自的样本数
minority_pct = 100 * count1 / (count0 + count1)                 # 计算类别 1 所占百分比
print(f'The percentage of diabetics is {minority_pct:.2f}%')     # 以两位小数显示比例
```

`value_counts()` 默认按计数从高到低排序，因此直接解包只适用于已确认类别 0 的样本更多这一数据集。更稳妥的通用写法是：

```python
counts = df['Outcome'].value_counts()                            # 按标签保存类别计数
count0, count1 = counts.loc[0], counts.loc[1]                    # 明确按标签 0 和 1 读取计数
```

## 指标：F1 与 ROC AUC

```python
predictions = random_forest.predict(X_val)                       # 得到验证集硬类别预测
f_score = f1_score(np.ravel(y_val), predictions)                # 综合正类精确率和召回率
score = round(f_score, 2)                                       # 保留两位小数用于汇总
auc_score = roc_auc_score(np.ravel(y_val), predictions)         # 按测试题写法计算单点 ROC AUC
auc = round(auc_score, 2)                                       # 保留两位小数用于汇总
```

> [!important]
> 测试题使用硬类别 `predictions` 计算 AUC；实际比较模型排序能力时，应优先传 `random_forest.predict_proba(X_val)[:, 1]`，这样会利用不同阈值下的完整 ROC 曲线。类别不平衡时，单看 Accuracy 容易掩盖少数类错误。

## 策略 1：不修正的 Random Forest

```python
random_forest = RandomForestClassifier(                          # 创建基线随机森林
    n_estimators=10, max_depth=20,                               # 使用 10 棵、最大深度 20 的树
    random_state=random_state,                                   # 固定随机性
)                                                               # 结束模型构造
random_forest.fit(X_train, np.ravel(y_train))                    # 使用原始训练数据拟合
```

## 策略 2：类别加权

```python
random_forest = RandomForestClassifier(                          # 创建带类别权重的森林
    n_estimators=10, max_depth=20,                               # 保持模型规模不变以便比较
    class_weight='balanced_subsample',                           # 每个 bootstrap 内反比加权类别
    random_state=random_state,                                   # 固定随机性
)                                                               # 结束模型构造
random_forest.fit(X_train, np.ravel(y_train))                    # 在未重采样的数据上拟合
```

## 策略 3：SMOTE 上采样

```python
sm = SMOTE(random_state=2)                                       # 创建可复现的合成少数类采样器
X_train_res, y_train_res = sm.fit_resample(                      # 只对训练集执行上采样
    X_train, np.ravel(y_train)                                   # 传入二维特征和一维标签
)                                                               # 返回重采样后的特征与标签
random_forest.fit(X_train_res, y_train_res)                      # 在上采样训练集上拟合模型
```

SMOTE 会在少数类近邻之间生成合成样本，而不是简单复制原样本。

## 策略 4：随机下采样

```python
sampler = RandomUnderSampler(random_state=2)                     # 创建可复现的多数类下采样器
X_train_res, y_train_res = sampler.fit_resample(                 # 只对训练集执行下采样
    X_train, np.ravel(y_train)                                   # 传入配对的特征和标签
)                                                               # 返回类别更均衡的训练数据
random_forest.fit(X_train_res, y_train_res)                      # 在下采样训练集上拟合模型
```

> [!warning]
> 必须先划分训练集和验证集，再只对训练集重采样。若在划分前对全数据 SMOTE 或下采样，会把验证信息泄漏到训练过程。
