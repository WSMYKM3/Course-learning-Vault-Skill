# 6.1 AdaBoost 自适应提升（Adaptive Boosting）

## 学习目标

- 用一句话说清 AdaBoost 在每一轮做什么。
- 理解“关注错题”在数学上就是提高被错分样本的权重。
- 会计算弱学习器的加权错误率、投票权和更新后的样本权重。
- 理解最终预测为什么是加权投票，而不是普通多数投票。
- 区分 AdaBoost、袋装法和随机森林的训练方式。
- 能用 scikit-learn 训练 AdaBoost，并知道主要参数的作用。

## 先抓住一句话

> **AdaBoost 让一组简单模型按顺序学习：下一轮更重视上一轮做错的样本，最后让表现更好的模型拥有更大的投票权。**

可以把它想成一个学生连续做几轮练习：

1. 第一轮，每道题同样重要。
2. 做错的题在下一轮获得更高权重，相当于被加入“重点错题本”。
3. 新的弱学习器会优先尝试解决这些高权重错题。
4. 多轮结束后，不是让所有学习器一人一票，而是让错误更少的学习器拥有更大的票。

这里有两种不同的权重，最容易混淆：

| 权重 | 作用对象 | 它回答的问题 |
| --- | --- | --- |
| [[样本权重 (Sample Weight)|样本权重]] $w_i$ | 第 $i$ 个训练样本 | 下一轮训练应该多重视这个样本？ |
| [[学习器权重 (Learner Weight)|学习器权重]] $\alpha_t$ | 第 $t$ 个弱学习器 | 最终投票时应该多相信这个学习器？ |

## 为什么简单模型可以组成强模型

AdaBoost 常用只有一次分裂的[[决策树桩 (Decision Stump)|决策树桩]]作为[[弱学习器 (Weak Learner)|弱学习器]]。一棵树桩只能画出一条简单的轴对齐边界，通常无法单独解决复杂分类问题。

但不同树桩可以关注不同区域：第一棵先解决大部分容易样本，第二棵集中解决第一棵的错题，第三棵再处理前两棵仍然困难的区域。把它们的判断加权相加后，整体[[决策边界 (Decision Boundary)|决策边界]]可以比任意一棵树桩更复杂。

“弱”不等于随便猜。对于二分类，弱学习器至少应比随机猜测好，即加权错误率通常要小于 $0.5$。

## AdaBoost 的四步循环

设训练集有 $n$ 个样本，二分类标签写为 $y_i\in\{-1,+1\}$。

### 第 0 步：初始化样本权重

一开始没有错题记录，所以每个样本同样重要：

$$
w_i^{(1)}=\frac{1}{n}
$$

### 第 1 步：训练一个弱学习器

使用当前样本权重训练第 $t$ 个学习器 $h_t(x)$。高权重样本的分类错误会让训练目标付出更大代价，因此学习器会更重视它们。

### 第 2 步：计算加权错误率和学习器权重

公式节点：[[AdaBoost加权错误率公式 (AdaBoost Weighted Error Formula)]]

$$
\varepsilon_t=\sum_{i=1}^{n} w_i^{(t)}\,\mathbf{1}\!\left(y_i\neq h_t(x_i)\right)
$$

只有被错分样本的权重会进入求和。然后计算学习器的投票权：

公式节点：[[AdaBoost学习器权重公式 (AdaBoost Learner Weight Formula)]]

$$
\alpha_t=\frac{1}{2}\ln\left(\frac{1-\varepsilon_t}{\varepsilon_t}\right)
$$

- $\varepsilon_t$ 越小，$\alpha_t$ 越大，最终越相信这个学习器。
- $\varepsilon_t=0.5$ 时，$\alpha_t=0$，它和随机猜测一样，没有贡献。
- $\varepsilon_t>0.5$ 时，$\alpha_t<0$；在标准二分类推导中，通常应反转其预测或停止检查，而不是把一个比随机还差的学习器原样加入。

### 第 3 步：更新样本权重

公式节点：[[AdaBoost样本权重更新公式 (AdaBoost Sample Weight Update Formula)]]

$$
w_i^{(t+1)}=
\frac{w_i^{(t)}\exp\!\left(-\alpha_t y_i h_t(x_i)\right)}{Z_t}
$$

其中 $Z_t$ 是归一化常数，使新一轮权重之和重新等于 $1$。

因为 $y_i$ 和 $h_t(x_i)$ 都是 $-1$ 或 $+1$：

- 预测正确时，$y_i h_t(x_i)=+1$，权重乘以 $e^{-\alpha_t}$，因此下降。
- 预测错误时，$y_i h_t(x_i)=-1$，权重乘以 $e^{+\alpha_t}$，因此上升。

之后回到第 1 步，继续训练下一个弱学习器。

## 最终预测：不是普通投票

公式节点：[[AdaBoost最终分类器公式 (AdaBoost Final Classifier Formula)]]

$$
H(x)=\operatorname{sign}\left(\sum_{t=1}^{T}\alpha_t h_t(x)\right)
$$

每个学习器输出 $-1$ 或 $+1$，再乘以自己的投票权。总分为正就预测 $+1$，总分为负就预测 $-1$。

例如，三个学习器对某个样本的预测分别是 $+1,-1,+1$，投票权分别为 $0.80,0.30,0.20$：

$$
0.80(+1)+0.30(-1)+0.20(+1)=0.70
$$

总分为正，最终预测 $+1$。注意：即使只有一个学习器投 $-1$，它也可能在权重足够大时超过多个较弱的 $+1$ 票。因此 AdaBoost 不是简单地数票数。

## 手算例子：第一轮如何产生“错题本”

假设有 5 个样本，真实标签和第一棵树桩的预测如下。初始时每个样本权重都是 $1/5=0.2$。

| 样本 | 真实 $y_i$ | 树桩 $h_1(x_i)$ | 是否正确 | 初始权重 |
| --- | ---: | ---: | --- | ---: |
| A | $-1$ | $-1$ | 正确 | 0.20 |
| B | $-1$ | $-1$ | 正确 | 0.20 |
| C | $+1$ | $-1$ | **错误** | 0.20 |
| D | $+1$ | $+1$ | 正确 | 0.20 |
| E | $+1$ | $+1$ | 正确 | 0.20 |

### 1. 计算加权错误率

只有 C 被错分，所以：

$$
\varepsilon_1=0.20
$$

### 2. 计算第一棵树桩的投票权

$$
\alpha_1=\frac{1}{2}\ln\left(\frac{1-0.2}{0.2}\right)
=\frac{1}{2}\ln(4)
\approx 0.693
$$

### 3. 更新样本权重

正确样本乘以 $e^{-0.693}\approx0.5$，错误样本 C 乘以 $e^{0.693}\approx2$：

| 样本 | 更新前 | 乘数 | 未归一化权重 | 归一化后权重 |
| --- | ---: | ---: | ---: | ---: |
| A | 0.20 | 0.5 | 0.10 | 0.125 |
| B | 0.20 | 0.5 | 0.10 | 0.125 |
| C | 0.20 | 2.0 | 0.40 | **0.500** |
| D | 0.20 | 0.5 | 0.10 | 0.125 |
| E | 0.20 | 0.5 | 0.10 | 0.125 |

未归一化权重之和是 $0.8$，所以每个值除以 $0.8$。结果是：被错分的 C 在下一轮独占 $50\%$ 的注意力。

这正是“后续模型关注前面错误”的精确含义。AdaBoost 不一定真的复制 C；它把 C 的训练损失放大了。

## 手算例子：第二轮为什么会改变关注点

假设第二棵树桩把高权重的 C 分对了，但把 A、B 分错。第二轮错误率不是 $2/5=0.4$，而是：

$$
\varepsilon_2=w_A+w_B=0.125+0.125=0.25
$$

所以：

$$
\alpha_2=\frac{1}{2}\ln\left(\frac{1-0.25}{0.25}\right)
=\frac{1}{2}\ln(3)
\approx0.549
$$

第二轮更新并归一化后，权重大约变为：

| 样本 | A | B | C | D | E |
| --- | ---: | ---: | ---: | ---: | ---: |
| 第二轮前 | 0.125 | 0.125 | 0.500 | 0.125 | 0.125 |
| 第二轮后 | **0.250** | **0.250** | 0.333 | 0.083 | 0.083 |

C 被正确分类后权重下降；A、B 被错分后权重上升。下一棵树桩会面对一份再次变化的“重点题清单”。

## 一个容易误解的地方

第二棵学习器不一定在未加权准确率上比第一棵更高。它的任务是在**当前权重分布**下表现良好。

在上面的第二轮中，A、B 两个样本被错分，但它们当时总权重只有 $0.25$；高权重的 C 被分对了。因此第二棵树桩的加权错误率仍然不错。AdaBoost 优化的是加权错误，而不只是错了几个样本。

## AdaBoost 与 Bagging / 随机森林

| 对比点 | AdaBoost | Bagging / 随机森林 |
| --- | --- | --- |
| 训练关系 | 按顺序训练，后一轮依赖前一轮结果 | 各基模型大体独立，可并行训练 |
| 如何制造差异 | 不断改变样本权重 | 对数据做自助采样；随机森林还随机选择特征 |
| 基模型常见选择 | 浅树，尤其是树桩 | 通常是较深的树 |
| 聚合方式 | 根据表现加权投票 | 分类多数投票，回归平均 |
| 主要直觉 | 逐轮修正当前错误，常用于降低偏差 | 平均多棵有差异的树，主要降低方差 |
| 对异常点的反应 | 可能反复提高难分点的权重，较敏感 | 通常不会持续追逐同一个错分点 |

最简记忆：**Bagging 是“大家独立做题后平均”，Boosting 是“看上一位的错题后接着做”。**

## 重要超参数

### `n_estimators`

弱学习器的最大数量。数量太少可能欠拟合；数量更多会提高表达能力和计算成本。AdaBoost 在已经得到完美拟合时可能提前停止。

### `learning_rate`

[[学习率 (Learning Rate)|学习率]]缩小每个学习器对整体模型的贡献。较小学习率通常需要更多学习器；这两个参数应一起调整。

### 基学习器复杂度

经典 AdaBoost 常使用 `max_depth=1` 的树桩。稍深的树可以学习特征交互，但也会让每轮模型更复杂。不要默认“树越深越好”。

## Python 示例：比较树桩与 AdaBoost

下面的例子先生成一个非线性二分类数据集，再比较单棵树桩和 100 棵树桩组成的 AdaBoost。代码使用当前 scikit-learn API 的 `estimator=` 参数。

```python
from sklearn.datasets import make_moons
from sklearn.ensemble import AdaBoostClassifier
from sklearn.metrics import accuracy_score, confusion_matrix
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

# 1. 生成一个带少量噪声的非线性数据集
X, y = make_moons(n_samples=800, noise=0.25, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.25,
    stratify=y,
    random_state=42,
)

# 2. 单棵树桩：只有一次分裂
stump = DecisionTreeClassifier(max_depth=1, random_state=42)
stump.fit(X_train, y_train)

# 3. AdaBoost：顺序训练多棵树桩
ada = AdaBoostClassifier(
    estimator=DecisionTreeClassifier(max_depth=1, random_state=42),
    n_estimators=100,
    learning_rate=0.5,
    random_state=42,
)
ada.fit(X_train, y_train)

# 4. 在同一个测试集上比较
stump_pred = stump.predict(X_test)
ada_pred = ada.predict(X_test)

print("Decision stump accuracy:", accuracy_score(y_test, stump_pred))
print("AdaBoost accuracy:", accuracy_score(y_test, ada_pred))
print("AdaBoost confusion matrix:\n", confusion_matrix(y_test, ada_pred))

# 5. 查看前几轮弱学习器的权重和错误率
print("First 5 learner weights:", ada.estimator_weights_[:5])
print("First 5 learner errors:", ada.estimator_errors_[:5])
```

阅读输出时关注三件事：

1. AdaBoost 的测试准确率是否高于单棵树桩。
2. `estimator_errors_` 越小的学习器，通常会得到越大的 `estimator_weights_`。
3. 不要只看训练准确率；最终判断模型时应查看测试集或交叉验证结果。

> 版本提醒：较旧的 scikit-learn 示例可能写 `base_estimator=`；现代版本已使用 `estimator=`。如果本机还没有 scikit-learn，可先在自己的 Python 环境中安装后运行。

> 公式约定提醒：本章手算使用经典二分类写法 $\alpha=\frac12\ln((1-\varepsilon)/\varepsilon)$。现代 scikit-learn 的分类器使用可推广到多分类的 SAMME 写法；二分类时它记录的学习器权重相当于去掉前面的 $\frac12$，并只显式放大错分样本。归一化后两种写法产生相同的样本相对权重，最终分类方向也相同。因此 `estimator_weights_` 的数值可能不是本章手算的 $0.693$，但这不代表计算错误。

## Python 示例：观察每增加一轮后的表现

`staged_score` 可以显示集成模型在第 1、2、3……轮之后的准确率：

```python
train_scores = list(ada.staged_score(X_train, y_train))
test_scores = list(ada.staged_score(X_test, y_test))

for round_no in [1, 5, 10, 25, 50, 100]:
    print(
        f"round={round_no:3d}",
        f"train={train_scores[round_no - 1]:.3f}",
        f"test={test_scores[round_no - 1]:.3f}",
    )
```

如果训练分数继续上升，而测试分数停止上升甚至下降，说明继续增加弱学习器已经没有改善泛化表现。可以通过交叉验证共同选择 `n_estimators`、`learning_rate` 和树深度。

## 常见错误与纠正

| 常见说法 | 问题 | 正确理解 |
| --- | --- | --- |
| “AdaBoost 每轮删除分对的样本” | 样本通常仍在训练集中 | 它降低分对样本的权重，提高错分样本的权重 |
| “每棵树都有同样一票” | 忽略了 $\alpha_t$ | 错误率更低的学习器投票权更大 |
| “第二棵树必须修正第一棵的所有错误” | 每棵弱学习器能力有限 | 它只需在当前加权数据上比随机猜测更好 |
| “错误率就是错分数量除以样本数” | 第二轮以后样本不再等权 | 应把错分样本的当前权重相加 |
| “AdaBoost 和随机森林只是树的数量不同” | 两者训练机制不同 | AdaBoost 顺序纠错；随机森林独立训练并聚合 |
| “更多弱学习器一定更好” | 忽略验证表现、噪声和计算成本 | 用验证集或交叉验证选择轮数 |

## 什么时候 AdaBoost 可能不理想

- 标签错误或异常点较多：这些样本可能被持续错分并得到越来越高的权重。
- 基学习器不支持样本权重：训练算法无法体现 AdaBoost 的关注点变化。
- 数据规模很大且需要充分并行：AdaBoost 的轮次相互依赖，训练不如 Bagging 容易并行。
- 需要非常透明的单条决策规则：多个树桩的加权组合不如单棵小树直观。

8. AdaBoost 和随机森林在训练顺序上有什么根本差异？
9. `learning_rate` 与 `n_estimators` 有什么关系？
10. 为什么 AdaBoost 可能对错误标签敏感？

## 复习检查参考答案

1. 每一轮都会根据上一轮的分类结果调整样本权重，使下一轮自适应地关注当前难分样本。
2. 样本权重决定下一轮多重视每个训练样本；学习器权重决定最终预测时多相信每个弱学习器。
3. 因为第一轮之后样本权重通常不同，错误率必须是错分样本权重之和。
4. $\varepsilon$ 越小，$\alpha=\frac12\ln((1-\varepsilon)/\varepsilon)$ 越大，模型的最终投票权越高。
5. 错分时 $y_i h_t(x_i)=-1$，更新公式中的乘数变为 $e^{+\alpha_t}>1$。
6. 每个学习器的可靠程度不同，所以预测要乘以各自的 $\alpha_t$ 后再求和。
7. $\alpha=0$；它相当于随机猜测，对最终分类没有贡献。
8. AdaBoost 按顺序训练，后一轮依赖前一轮更新的样本权重；随机森林的树大体独立，可以并行训练。
9. 较小学习率会缩小每轮贡献，通常需要更多学习器；二者应一起调节。
10. 错误标签可能长期被错分，权重不断提高，使后续学习器浪费能力追逐无法正确学习的噪声。

## 一句话总结

AdaBoost 用“错题加权 + 学习器加权”的顺序训练，把许多只比随机猜测好一点的弱学习器组合成一个更强的分类器。
