# 分割标准（Splitting Criteria）

分割标准用于比较不同特征和阈值产生的分割效果，目标是让分割后的区域更纯净。

常见标准：[[分类错误率 (Classification Error Rate)]]、[[基尼指数 (Gini Index)]]、[[熵 (Entropy)]]。
