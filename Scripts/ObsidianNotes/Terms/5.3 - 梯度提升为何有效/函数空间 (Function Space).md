# 函数空间（Function Space）

函数空间把每一个完整函数视为一个可能的解。梯度提升不是只在固定维度的参数向量中移动，而是通过逐棵加入弱学习器，从当前预测函数移动到新的预测函数。

相关概念：[[预测空间 (Prediction Space)]]、[[非参数模型 (Nonparametric Model)]]、[[梯度下降 (Gradient Descent)]]、[[梯度提升 (Gradient Boosting)]]
