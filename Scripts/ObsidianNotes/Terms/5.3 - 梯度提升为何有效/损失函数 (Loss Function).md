# 损失函数（Loss Function）

损失函数用数值衡量模型预测与目标之间的不一致，训练过程试图最小化它。梯度提升在每轮计算损失相对于当前预测的负梯度，并训练新树去近似这个方向。

相关概念：[[均方误差 (Mean Squared Error)]]、[[梯度下降 (Gradient Descent)]]、[[伪残差 (Pseudo-Residual)]]、[[可微 (Differentiable)]]
