# 基模型（Base Model）

基模型是集成学习中被单独训练的一个模型，也称为基学习器。袋装法中常用深度决策树作为基模型，再把多棵树的预测结果聚合起来。

相关概念：[[集成学习 (Ensemble Learning)]]、[[决策树 (Decision Tree)]]、[[袋装法 (Bagging)]]
