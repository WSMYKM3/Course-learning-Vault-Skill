# 自助采样（Bootstrap Sampling）

自助采样是从原始数据集中进行有放回抽样，生成与原始数据集大小相同的新数据集的方法。袋装法通过多次自助采样得到多个训练集，从而训练出多个有差异的基模型。

相关概念：[[有放回抽样 (Sampling with Replacement)]]、[[自助数据集 (Bootstrap Dataset)]]、[[袋装法 (Bagging)]]
