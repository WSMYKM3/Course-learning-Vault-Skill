# 自助数据集（Bootstrap Dataset）

自助数据集是通过自助采样从原始训练集中生成的数据集。它通常与原始训练集大小相同，但因为采用有放回抽样，所以会包含重复样本，也会遗漏一部分原始样本。

相关概念：[[自助采样 (Bootstrap Sampling)]]、[[有放回抽样 (Sampling with Replacement)]]、[[袋外误差 (Out-of-Bag Error)]]
