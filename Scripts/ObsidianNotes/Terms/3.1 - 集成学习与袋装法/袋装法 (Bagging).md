# 袋装法（Bagging）

袋装法是 Bootstrap Aggregating 的缩写，指先用自助采样生成多个训练集，再在每个训练集上训练一个基模型，最后聚合这些模型的预测。它常用于降低高方差模型的方差，例如把多棵深决策树组合起来。
