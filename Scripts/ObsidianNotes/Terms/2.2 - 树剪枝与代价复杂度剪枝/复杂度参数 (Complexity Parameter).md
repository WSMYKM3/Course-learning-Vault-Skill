# 复杂度参数（Complexity Parameter）

复杂度参数通常记作 $\alpha$，用于控制代价复杂度剪枝中对树复杂度的惩罚强度。$\alpha$ 越大，叶节点数量带来的惩罚越强，模型越倾向于选择更小的树。
