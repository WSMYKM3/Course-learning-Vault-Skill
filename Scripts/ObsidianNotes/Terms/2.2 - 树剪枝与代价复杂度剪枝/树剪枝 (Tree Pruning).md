# 树剪枝（Tree Pruning）

树剪枝是在先生成一棵较复杂的决策树后，再移除一些分支或子树，以降低模型复杂度并缓解过拟合的方法。它与预先设置停止条件不同，剪枝通常先让树充分生长，再从复杂树中寻找更简单、泛化能力更好的子树。
