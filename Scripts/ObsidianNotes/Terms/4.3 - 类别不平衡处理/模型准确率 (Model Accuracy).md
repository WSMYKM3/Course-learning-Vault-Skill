# 模型准确率（Model Accuracy）

模型准确率是分类任务中预测正确样本所占的比例。置换重要性可以通过比较置换前后的验证集或袋外准确率变化来衡量特征重要性；在类别不平衡数据中，准确率也可能掩盖少数类预测失败。
