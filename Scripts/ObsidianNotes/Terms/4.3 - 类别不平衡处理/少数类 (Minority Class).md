# 少数类（Minority Class）

少数类是在分类数据集中样本数量明显较少的类别。在疾病检测或欺诈检测中，少数类往往是更值得关注的目标类别。

相关概念：[[多数类 (Majority Class)]]、[[类别不平衡 (Class Imbalance)]]、[[过采样 (Oversampling)]]
