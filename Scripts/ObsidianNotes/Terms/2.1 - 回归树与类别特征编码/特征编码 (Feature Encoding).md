# 特征编码（Feature Encoding）

特征编码是把非数值特征转换为模型可处理的数值表示的方法。对于类别型特征，常见方法包括整数编码、独热编码和哑变量编码。

相关概念：[[类别型特征 (Categorical Feature)]]、[[独热编码 (One-Hot Encoding)]]、[[哑变量编码 (Dummy Variable Encoding)]]
