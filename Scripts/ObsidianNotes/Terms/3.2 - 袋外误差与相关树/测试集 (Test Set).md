# 测试集（Test Set）

测试集是从模型训练和超参数选择过程中隔离出来的数据，仅用于最终估计已选模型的泛化表现。反复根据测试集结果修改模型，会让测试集逐渐承担验证集的角色，并造成评估泄漏。

相关概念：[[训练数据 (Training Data)]]、[[验证集 (Validation Set)]]、[[泛化误差 (Generalization Error)]]、[[数据泄漏 (Data Leakage)]]、[[超参数调优 (Hyperparameter Tuning)]]
