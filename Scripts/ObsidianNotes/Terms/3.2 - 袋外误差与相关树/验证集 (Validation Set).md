# 验证集（Validation Set）

验证集是从训练数据中留出或划分出来、用于比较模型设置或估计模型表现的数据。它不应参与对应模型的训练，否则评估结果可能受到数据泄漏影响。与只用于最终评估的测试集不同，验证集可以参与模型和超参数选择。
